# Employee Payroll Management System

## 📌 Project Overview

The **Employee Payroll Management System** is a Python-based console application designed to manage employee information and salary details efficiently.

This project helps administrators maintain employee records, manage salary information, and perform basic employee management operations through a simple menu-driven interface.

It is developed using Python and focuses on fundamental programming concepts such as functions, lists, conditional statements, loops, and user input handling.

## 🚀 Features

- **Admin Login:** Secure access to the employee management system.
- **Add Employee:** Add new employees with their personal and professional details.
- **Remove Employee:** Remove employee records using their name.
- **View Employee:** Display the details of a particular employee.
- **View All Employees:** Display all registered employee records.
- **Salary Management:** Store and manage employee salary information.
- **Logout:** Safely exit the admin panel.

## 🛠️ Technologies Used

- Python 3
- Lists
- Functions
- Conditional Statements
- Loops
- User Input and Output

## 📂 Employee Information

The system maintains the following employee details:

- Employee ID
- Employee Name
- Age
- Gender
- Department
- Salary

## ⚙️ How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or any Python IDE.
4. Run the Python file.

```bash
python Employee_Payroll_Management_System.py
```

5. Enter the admin login credentials.
6. Select the desired operation from the menu.
